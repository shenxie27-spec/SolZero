# Seeker / Solana dApp Store 政策摘要（2026-07 官方最新版）

> 来源：docs.solanamobile.com / solanamobile.com/publisher-policy-web（2026-07-21 更新）

## 与 SolZero 直接相关的要点

- **0 抽成**：商店目前不收取任何上架、内购、订阅费用。SolZero 的 10% 为自有服务费，必须明示。
- **上架形式**：签名 APK，经 publish.solanamobile.com 提交，审核约 3-5 个工作日；应用列表本身是链上 NFT。
- **误导性内容禁止**：不得误导用户对应用的「真实意图、性质或目的」——因此积分福利只表述为「更多会员权益」，不承诺空投/发币/分红。
- **用户数据**：必须有隐私政策；须提供删除账号及删除数据的途径；不得欺诈性获取同意。
- **受监管数据**（含金融凭证）：最少化收集 + 加密 + 最佳实践。SolZero 不接触私钥（Seed Vault/MWA），仅收集钱包公钥与业务数据。
- **金融服务条款**：提供受监管金融服务需具备相应资质文件。SolZero 定位为工具软件，收取工具服务费，不提供投资建议、不托管资产。
- **安全**：不得引入或利用安全漏洞；不得干扰其他应用。
